Summary

TARGET LOAD (จำนวนงานที่ควรโหลด)

ชั่วโมงนี้ควรป้อนงานเข้าไลน์เย็บอีกเท่าไร

คิดจาก: เป้าของชั่วโมงนี้ลบงานที่ค้างในสายอยู่แล้ว ถ้าได้ผลบวกให้ป้อนเพิ่มตามส่วนที่ขาด แล้วเผื่ออีก 25% เพื่อกันงานขาดมือ ถ้างานค้างมากกว่าเป้าแล้วไม่ต้องป้อนเพิ่ม (เป็น 0)

ตัวอย่าง: เป้า 75 แต่งานค้าง 229 จึงไม่ต้องป้อนเพิ่ม = 0 ถ้าเริ่มวันด้วยงานค้าง 0 สายควรได้รับ 75 × 1.25 = 93.75 หรือประมาณ 94 ชิ้น

ACTUAL LOAD (งานที่ป้อนเข้า/งานที่โหลดเข้า)

จำนวนงานที่ถูกโหลดเข้าไลน์เย็บในชั่วโมงนั้น ระบบหลังบ้านนับให้ หน้าจอแค่แสดงผล

สีบอกว่าป้อนงานพอดีไหม โดยเทียบกับ TARGET LOAD (จำนวนที่ไลน์เย็บควรได้รับ)

  • ส้ม = ป้อนงานเกินกว่าที่สายต้องการมาก (เกิน 1.25 เท่าของที่ควรได้)
  • ฟ้า = ป้อนงานน้อยกว่าที่สายควรได้
  • ขาว = อยู่ในช่วงที่ยอมรับได้

ตัวอย่าง: ถ้างานค้างในสายเยอะอยู่แล้ว ช่อง TARGET LOAD จะเป็น 0 ถ้ายังป้อนงานเพิ่ม ช่องนี้จะเป็นสีส้ม

HOURLY TARGET (เป้าของชั่วโมงนั้น)

เป้าปกติของชั่วโมงนั้น บวกยอดที่ต้องไล่ตามให้ทัน

ถ้าชั่วโมงก่อนๆ ทำได้ไม่ถึงเป้า ยอดที่ขาดจะถูกแบ่งไปเพิ่มในชั่วโมงที่เหลือของวัน โดยแบ่งตามเวลาทำงานที่เหลือ

ตัวอย่าง: ชั่วโมงแรกเป้า 75 ทำ QC ได้ 25 ขาดไป 50 เหลือเวลาทำงาน 7 ชั่วโมง ชั่วโมงที่สองจึงรับยอดเพิ่มประมาณ 7 ชิ้น เป้าเป็น 75 + 7 = 82 ยิ่งใกล้เลิกงาน เวลาเหลือน้อย ยอดที่ต้องไล่ตามยิ่งสูง ชั่วโมงสุดท้ายเป้าจึงพุ่งเป็น 264

QC PASS (งานที่ตรวจผ่าน)

จำนวนงานที่ผ่านการตรวจคุณภาพในชั่วโมงนั้น นับรวมงานที่แก้แล้วกลับมาผ่านด้วย

ลูกศรเล็กข้างตัวเลขคือยอดที่ตามหลัง/นำเป้าสะสม คิดจากผลรวม QC ที่ทำได้ตั้งแต่เริ่มวัน ลบผลรวมเป้าตั้งแต่เริ่มวัน

  • ลูกศรลงสีแดง = ตามหลังเป้าอยู่เท่านี้ชิ้น
  • ลูกศรขึ้นสีเขียว = ทำได้เกินเป้าสะสม
  • ไม่มีลูกศร = เท่ากับเป้าพอดี

ตัวอย่าง: ถึงชั่วโมง 10:00-11:00 ทำ QC สะสมได้ 115 ชิ้น แต่เป้าสะสม 245 ชิ้น จึงแสดง ↓130

BALANCE WIP (งานค้างในสาย)

งานที่ยังอยู่ในสายเย็บ ยังไม่ผ่าน QC ออกไป

งานค้างตอนนี้ = งานค้างชั่วโมงก่อน + งานที่ป้อนเข้าใหม่ − งานที่ผ่าน QC ออกไป

ตัวอย่าง: เริ่มวันมีงานค้าง 172 ชั่วโมงแรกป้อนเข้า 82 ผ่าน QC 25 งานค้างจึงเป็น 172 + 82 − 25 = 229 แล้วใช้ 229 เป็นจุดเริ่มของชั่วโมงถัดไป

SCAN BOX (งานที่สแกนกล่องแล้ว)

จำนวนงานที่สแกนกล่อง/ส่งต่อในชั่วโมงนั้น

  • ตัวเลขเป็น สีเขียว เมื่อสแกนได้มากกว่า 0 และถึงเป้าของชั่วโมงนั้น
  • ลูกศรอ่านแบบเดียวกับ QC PASS คือผลรวมสแกนสะสมเทียบกับเป้าสะสม
  • ช่องนี้ไม่ถูกนำไปคิดงานค้าง (Balance WIP) ซึ่งใช้ตัวเลข QC PASS
